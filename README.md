## 📌 Overview

**Party Mania** is a two-player cooperative platformer built entirely in **Godot** using **GDScript**, submitted to the NC TSA (Technology Student Association) Video Game Design competition. Two players share a screen, navigate four themed worlds filled with obstacles and puzzles, and race to collect party supplies to throw William the ultimate birthday bash.

---

## 📖 Story

Stephanie and Sullivan are on a mission — their son **William's birthday party** won't plan itself! Journey through 4 unique worlds, dodge obstacles, solve puzzles, and gather everything needed to throw an unforgettable celebration.

---

## 🗺️ Levels

| # | Level | Objective |
|:---|:---|:---|
| 1 | 🎂 **Cake Kingdom** | Navigate twisting falls and spike traps to grab the cake |
| 2 | 🎊 **Confetti Connections** | Solve maze puzzles to collect confetti and party horns |
| 3 | 🎈 **Sweet Meadows** | Platform through floating islands to collect balloons |
| 4 | 🍫 **Cocoa Quest** | Conquer the final challenge and retrieve William's present |

## 🎮 Controls

### Sullivan — `WASD`

| Key | Action |
|:---|:---|
| `W` | Jump |
| `A` | Move Left |
| `S` | Move Down |
| `D` | Move Right |
| `W` + `W` | Double Jump *(Levels 1, 3 & 4)* |

### Stephanie — `Arrow Keys`

| Key | Action |
|:---|:---|
| `↑` | Jump |
| `←` | Move Left |
| `↓` | Move Down |
| `→` | Move Right |
| `↑` + `↑` | Double Jump *(Levels 1, 3 & 4)* |

## 🛠️ Tech Stack

| Tool | Purpose |
|:---|:---|
| **Godot Engine** | Game engine — scene graph, physics, rendering |
| **GDScript** | Game logic, player controllers, level scripting |
| **Split Screen** | Simultaneous dual-viewport co-op rendering |
| **GitHub Pages** | Live web deployment of the exported Godot build |

---

## ⚙️ Key Systems Built

- 🔀 **Split-screen co-op** — dual viewport rendering with synchronized game state
- 🔄 **Respawn system** — checkpoint-based respawning per player
- 🧩 **Checkpoint system** — mid-level save points tracking both players
- 🕹️ **Double jump mechanic** — enabled per-level with tunable physics
- 🎬 **Lobby + dialogue system** — animated intro with character dialogue
- 🎵 **Lobby music + SFX** — ambient audio and level sound effects
